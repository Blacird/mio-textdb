# MIO 文本库（四语对照）

《MIO: Memories in Orbit》游戏文本的离线检索工具，收录 **2,155 条**文本，
含 **简体中文 / 繁体中文 / 英语 / 法语** 对照。

## 使用

打开 `index.html` 即可（也可直接访问 GitHub Pages 地址）。

- 左侧顶部为类别索引，角色 / 区域 / 子类下拉随类别动态变化
- 点击任意条目弹出浮窗，四语全文阅读
- 若页面数据过多，滚动会自动加载

单文件、无外部依赖、不联网即可运行。

## 数据来源

游戏内本地化表 `assets/loc/` 下的 `spoken.csv`、`non_spoken.csv`、`other.csv`、`credits_EXPORT.csv`，
原始表含 15 种语言，本项目仅取简中 / 繁中 / 英语 / 法语四列。

原始 CSV 始终保持只读，未作任何修改。
